# Como testar no seu aparelho

## iPhone (navegador Safari)

O iPhone não instala APK, e um app de iPhone exige Mac e conta paga da Apple.
Por isso a versão para iPhone é a página web, publicada pelo CI a cada entrega
(D-022):

1. No iPhone, abra no Safari: https://lucaskaeller201-ui.github.io/Pipa-Brasil/
2. Espere carregar (na primeira vez demora mais; depois fica guardado).
3. Para ocupar a tela toda: botão Compartilhar → **Adicionar à Tela de Início**,
   e abra pelo ícone criado.

## Android (celular)

1. No celular, abra a página do repositório no GitHub, logado na sua conta.
2. Toque em **Releases** e depois em **Última versão (automática)**.
3. Baixe `pipa-brasil.apk`.
4. Abra o arquivo baixado. Na primeira vez o Android pede para permitir a
   instalação de "fontes desconhecidas" para o navegador: permita.
5. Abra o PIPA BRASIL.

## Windows (PC)

1. Na mesma página, baixe `pipa-brasil-windows.zip`.
2. Descompacte e abra `pipa-brasil.exe`.
3. Se o Windows mostrar "O Windows protegeu o computador", clique em
   **Mais informações** e depois em **Executar assim mesmo** (o executável não
   tem assinatura paga).

## O que observar em cada fase

A lista de verificação de cada fase fica em `docs/progresso.md`. Ao testar,
anote o modelo do aparelho, o FPS mostrado na tela e o que estranhou.
